# Migurei

Migurei（株式会社エイチビーラボジャパンの子会社）は、企業向けの AI プロダクトを開発しています。
公式サイト: https://migurei.ai

## プロダクト

- **Parallel World**：ウェブサイトが AI エージェントにどう見えているかを測定・監視するサービス。無料スキャンあり、スキャンは読み取り専用。 https://migurei.ai/ja/applications/parallel-world
- **M-RAG**：RAG（検索拡張生成）技術を組み合わせたチャットボットソリューション。 https://migurei.ai/ja/applications/ai-chatbot
- **M-Trans**：Google Workspace（Sheets・Slides・Docs）の書式を保ったまま多言語に翻訳する AI 翻訳。 https://migurei.ai/ja/applications/ai-translation
- **M-Meeting**：リアルタイム翻訳、ライブ字幕、音声通訳、AI 議事録をひとつにした会議アシスタント。 https://migurei.ai/ja/applications/ai-meeting
- **M-Workspace**：役割別エージェントでワークフローを自動化する統一プラットフォーム。 https://migurei.ai/ja/applications/ai-workspace
- **M-Avatar**：音声と同期して動く AI アバター。英語・日本語・韓国語の音声クローニングに対応。 https://migurei.ai/ja/applications/ai-avatar
- **M-Hub**：一度のログインで全アプリを利用でき、組織・メンバー・ロールと AI トークン使用量をまとめて管理するポータル。 https://migurei.ai/ja/applications/hub

## このアカウントのリポジトリ（Parallel World）

- [ai-bot-registry](https://github.com/Migurei/ai-bot-registry)：AI クローラー・AI エージェントの UA、IP レンジ、AI アプリのリファラー（JSON）。
- [ai-bot-check-skill](https://github.com/Migurei/ai-bot-check-skill)：サイトが AI クローラー・AI エージェントを受け入れているかをコーディングエージェントに確認させる Agent Skill。
